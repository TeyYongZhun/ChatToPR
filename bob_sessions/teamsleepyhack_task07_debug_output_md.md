### What changed

**Four new pure functions added before the existing `getOctokit` helper:**

| Function | What it does |
|---|---|
| [`extractParticipants()`](src/app/api/triage/route.ts) | De-dupes `m.user` across the thread via `Set` |
| [`extractRefs()`](src/app/api/triage/route.ts) | Finds every `#<number>` token (ticket/PR refs) with a stateful `RegExp.exec` loop |
| [`extractCodeRefs()`](src/app/api/triage/route.ts) | Finds every `` `backtick-quoted` `` span (inline code refs) the same way |
| [`classifyMessages()`](src/app/api/triage/route.ts) | Scans for root-cause / fix / rollback language and returns the first matching message for each; falls back to `undefined` |
| [`buildIncidentRecord()`](src/app/api/triage/route.ts) | Calls the above four, then assembles the full Markdown: summary table → root-cause blockquote → fix blockquote → rollback blockquote → timeline table |

**Inside `POST`:**

- `incidentId` derived from `Date.now().toString().slice(-6)` — short, unique, numeric
- `targetFile` changed from `"sample.txt"` → `` `triage/INC-${incidentId}.md` ``
- `commitMessage` changed to `` `incident: add INC-${incidentId} triage record` ``
- `branchName` changed to `` `triage/INC-${incidentId}` `` (human-readable, matches the file)
- Content committed is now `incidentRecord` (the built Markdown) instead of raw message texts
- PR body now includes the incident ID and the committed file path
